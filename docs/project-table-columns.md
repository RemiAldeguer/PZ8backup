# Colonnes des listings de projets

Dans « Tous les projets » et les tableaux de zone, le bouton **Colonnes** permet de choisir les colonnes visibles et leur ordre. Le nom du projet reste obligatoire. Les champs personnalisés de portée projet sont disponibles, masqués par défaut. Les colonnes financières suivent les droits de budget existants.

Les bords des en-têtes permettent de redimensionner les colonnes, y compris dans la liste des tâches d’un projet. Double-clic : largeur initiale. Au clavier : flèches gauche/droite (10 px, 50 px avec Maj), Début/Fin (bornes). Échap annule le glissement en cours.

Ces préférences sont stockées dans le navigateur, par compte connecté. Le tableau des projets partage sa configuration entre les zones ; les listes de tâches gardent une configuration par projet. Elles ne modifient ni les données métier ni les autorisations.

Validation ciblée : configuration, champ personnalisé, glissement/clavier/annulation, persistance après rechargement, changement de compte et refus des colonnes financières ; redimensionnement après réorganisation de la liste ; totaux de zone et défilement mobile. Les tests navigateur utilisent une base temporaire.
