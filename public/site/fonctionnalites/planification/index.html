Un planning est utile quand chacun peut comprendre ce qui doit être fait, dans quel ordre et pour quelle échéance. Planzone 8 rassemble la structure du projet et ses éléments dans plusieurs vues, pour préparer les étapes comme pour suivre le travail quotidien.

Construire une structure qui reflète votre projet

Organisez le travail par phase, par livrable ou par équipe. Les listes peuvent contenir des tâches, des jalons et d’autres listes. Cette hiérarchie permet de commencer avec quelques grandes étapes, puis de détailler progressivement le plan.

Dans la vue Liste, déplacez un élément avant, après ou dans une liste. Les sous-listes suivent leur parent. Les éléments sont conservés avec leur identité, leurs commentaires et leur historique.

  • Regrouper les actions d’un même livrable.
  • Conserver un ordre manuel lisible.
  • Replier les détails pour préparer une réunion.

Lire le planning dans le Gantt

Le Gantt situe les éléments sur un axe temporel et reprend la structure du projet. Les barres des listes résument les dates de leurs descendants ; les jalons marquent les points de passage. Les éléments sans date restent accessibles pour être préparés ensuite.

Zoomez pour examiner une période ou prendre du recul. Le panneau Détails peut afficher les dates, l’alloué, le passé, les tags et les champs personnalisés utiles à votre lecture.

Ajuster les dates et expliciter les dépendances

Dans le Gantt de projet, les poignées permettent de modifier le début ou la fin d’une tâche ; le déplacement de sa barre déplace sa période. L’aperçu montre les nouvelles dates avant l’enregistrement. Les mêmes dates se retrouvent ensuite dans la vue Liste.

Une contrainte fin → début relie deux éléments du même projet. Elle indique que le prédécesseur doit être terminé avant de démarrer le suivant. Les contraintes sont visibles sur le planning ; les changements de lien ne déplacent pas automatiquement les dates.

Choisir une vue selon le moment

La Liste est adaptée à la préparation détaillée. Le Tableau facilite la lecture des statuts. Le Gantt présente les dates et les liens. Le Calendrier replace les tâches, les jalons et les événements dans les journées.

Vous pouvez passer d’une vue à une autre pour préparer un point d’équipe, rechercher une tâche ou suivre une échéance. La structure reste commune au projet.

EN PRATIQUE

Exemple : préparer un lancement de produit

Créez une liste Cadrage, une liste Conception et une liste Lancement. Dans chacune, détaillez les tâches et leurs responsables. Ajoutez un jalon de validation, puis reliez les actions qui nécessitent cette validation. La vue Gantt sert à lire le calendrier ; le Tableau accompagne le suivi quotidien.
